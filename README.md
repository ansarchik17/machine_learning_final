# Student Outcome Classification and Academic Profile Analysis

Классификация образовательных исходов студентов и анализ академических профилей.

Репозиторий: [ansarchik17/machine_learning_final](https://github.com/ansarchik17/machine_learning_final).

Выбран новый датасет **Predict Students' Dropout and Academic Success**, UCI ID 697.
Рабочий дедлайн: **23 ноября 2026 года**.

## Текущий статус

Численная часть выполнена: тренировочный EDA, baseline, три классических алгоритма,
CV и tuning, четыре кандидата ANN, K-Means, PCA, сравнение групп признаков и анализ
ошибок. Полный численный эксперимент повторён с тем же планом; метрики и выбранные
настройки воспроизвелись. Аннотированный notebook выполняется в локальном ядре
`students-dropout`. Подготовлены обзор литературы и APA-библиография: 26 источников,
из них 19 рецензируемых работ. Подготовлены PDF-отчёт на 21 страницу и research
proposal на 3 страницы; документы проверены по сохранённым результатам и рендеру
всех страниц. Команде остаётся проверить содержание, подготовить презентацию и
зафиксировать фактический вклад студентов.

## Исследовательский вопрос

**Как меняется качество классификации исхода обучения при добавлении результатов
первого и второго семестров?**

Тип задачи: multiclass classification. Target: `Dropout`, `Enrolled`, `Graduate`.
`Enrolled` остаётся самостоятельным классом: продолжение обучения не равнозначно
ни отчислению, ни гарантированному выпуску.

Основной профиль признаков включает результаты первого семестра. Дополнительно
сравниваются профиль без семестровых показателей и профиль с обоими
семестрами. Это ретроспективное сравнение информации, а не доказательство
работоспособности системы раннего предупреждения на конкретную дату.
Финансовые статусы `Debtor` и `Tuition fees up to date` исключены из всех основных
профилей из-за неустановленной даты их наблюдения. Расширение с ними допустимо
только как отдельно обозначенный исторический эксперимент.

## План оценки

- Один общий stratified split 70/15/15: **3 096 train, 664 validation, 664 test**;
  random seed **42**. Принадлежность строк сохранена до обучения и общая для
  всех моделей и профилей.
- Основная метрика: **Macro F1**. Дополнительные: recall/precision класса Dropout,
  balanced accuracy, accuracy и confusion matrix.
- Baseline: DummyClassifier. Кандидаты из классических методов: Logistic Regression,
  Decision Tree, KNN. Не менее двух нужно сверить с фактической программой лекций.
- Cross-validation выполнена для всех трёх классических алгоритмов и дополнительных
  logistic-профилей: stratified 5-fold внутри train. ANN настраивается по validation
  с восстановлением лучшего checkpoint. Протокол финального test общий.
- Подбор параметров и early stopping используют train/CV/validation. Test не
  используется для выбора моделей и параметров.
- Обучаемые преобразования подгоняются только на train, а при CV внутри каждого
  обучающего fold. Итоговое сравнение моделей проводится на одних и тех же строках.
- Дисбаланс сначала оценивается на исходных данных; веса классов можно сравнить
  на train/validation. Критерий успеха: улучшить Macro F1 относительно baseline;
  измеренные значения приведены ниже и в итоговой таблице.

## Измеренные результаты

Основной профиль: 28 исходных признаков первого семестра и 4 производных; после
train-fitted one-hot encoding и подготовки получается 229 входов. Во всех основных
моделях одинаковые строки и одинаковая доступная информация.

| Модель | Validation Macro F1 | Test Macro F1 | Test accuracy |
| --- | ---: | ---: | ---: |
| Dummy | 0.2222 | 0.2218 | 0.4985 |
| Logistic Regression | 0.6535 | 0.6899 | 0.7304 |
| Decision Tree | 0.5893 | 0.6356 | 0.6657 |
| KNN | 0.5416 | 0.5871 | 0.7033 |
| **ANN, выбрана по validation** | **0.6625** | **0.6785** | **0.7289** |

ANN: 229-32-3, ReLU/softmax, 7 459 параметров, L2 alpha 0.01, Adam с learning rate
0.001, batch 64, веса классов из train. Восстановлена эпоха 9, остановка на эпохе 34.
Рост train F1 при ухудшении validation после раннего checkpoint показывает переобучение.
Logistic Regression оказалась выше на test, но это не меняет выбор, сделанный по
validation, и не используется для донастройки.

Для Logistic Regression в сравнении групп признаков test Macro F1 составил:
0.5683 без семестровых результатов, 0.6899 с первым семестром, 0.7255 с обоими.
Это отдельная ablation с одинаковым grid/CV и общим разбиением, а не утверждение
о доступности признаков в индивидуальную дату.

K-Means: k=3, silhouette 0.6002, mean seed ARI 1.0. Минимальная доля кластера 5.91%.
Выбор учитывает заранее установленный минимум 5%, а не одну silhouette.
Группы описывают обычную академическую нагрузку, почти полное отсутствие сданных
дисциплин и повышенную зарегистрированную нагрузку. Их размеры: 2 401, 512 и 183.
Первые две PCA-компоненты сохраняют 77.80% дисперсии; для 95% нужны 4 компоненты.

Выбранная ANN ошиблась в 180 из 664 test-наблюдений. Recall Dropout: 72.43%; recall
Enrolled: 51.26%. Это указывает на конкретные ограничения, которые нужно обсуждать
в отчёте. Предсказания и confusion matrix сохранены для проверки.

Численные таблицы: `artifacts/tables/final_comparison.csv`, `feature_ablation.csv`,
`test_class_metrics.csv`, `test_error_groups.csv`. В папке `artifacts/figures/` 12
графиков, включая 5 EDA. Обученные модели находятся в `artifacts/models/`.
Проверки: `artifacts/verification.json`, повторный запуск: `artifacts/reproducibility.json`.

Код подготовки признаков и split находится в `src/data.py`, обучение и метрики
в `src/workflow.py`, построение графиков в `src/plots.py`. Notebook показывает
этапы, таблицы, графики и интерпретации, используя эти исполняемые модули.

## Ограничения интерпретации

Нет индивидуальных дат отчисления и явного поля года поступления в CSV, поэтому
обычное случайное разбиение не доказывает переносимость на будущие наборы студентов.
Нельзя утверждать, что все семестровые данные были доступны до наступления исхода.
При сравнении временных профилей финансовые и другие меняющиеся статусы требуют
отдельной проверки доступности.

Сведения о семье, возрасте и других характеристиках требуют содержательной
интерпретации; корреляции не устанавливают причин. Результат исследования не
является основанием для автоматического отчисления. Назначение потенциального
применения - выявлять потребность в поддержке, с последующей внешней проверкой.
