# Рабочий процесс

- По просьбе пользователя после каждой завершённой задачи сразу делать commit и push в `origin`.
- Перед коммитом проверить `git status` и состав изменений; не включать посторонние пользовательские правки.
- Не коммитить `.venv`, кеши Python, локальные секреты и файлы `.env`.
- Выполнять проверки, соответствующие изменениям. Для изменений численной части:
  `.venv/bin/python -m unittest discover -s tests -v` и
  `.venv/bin/python scripts/verify_outputs.py`.
- Соблюдать зафиксированный протокол оценки из `project_config.json` и
  `artifacts/experiment_plan.json`; результаты test не использовать для донастройки.
- В ответе кратко сообщать результат и ссылку на отправленный коммит.
